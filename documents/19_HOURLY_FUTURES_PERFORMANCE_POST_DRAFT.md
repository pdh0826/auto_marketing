# Hourly Futures Performance Post Draft

## 목적

정규 선물 시황 글과 별도로, 매 정각 급등포착 선물 6종의 `10분봉`을 확인하고 최근 완료 거래 성과가 실제로 좋아진 상품만 티스토리 추가 포스팅 후보로 만든다.

대상은 다음 여섯 상품이다.

- KOSPI200 선물
- E-mini NASDAQ100 선물
- E-mini S&P500 선물
- WTI 크루드오일 선물
- 금 선물
- 유로/달러 선물

정각마다 글을 무조건 만들지 않는다. 스캔은 매시간 실행하되, 검증된 새 수익 거래가 없으면 기록만 남기고 종료한다.

## 정각 실행 순서

1. 각 상품의 `10분봉` 구조화 데이터를 수집한다.
2. 이전 정각 snapshot과 `완료 거래 수`, `누적 실현 손익(pt)`, `관측 시각`을 비교한다.
3. 완료 거래 수가 늘었고 누적 실현 손익 증가분이 양수인 상품만 1차 후보로 둔다.
4. 상품별 point 단위가 다르므로 절대 pt만 비교하지 않는다. 최근 30일 상품별 성과 분포 또는 ATR 정규화 점수로 후보 우선순위를 계산한다.
5. 후보 상품의 10분봉 화면을 새로 열어 최근 진입·청산 표식이 보이도록 캡처한다.
6. 구조화 데이터와 차트 표식이 같은 거래 방향과 결과를 가리키는지 검증한다.
7. 기존 Project300 말투·SEO·자연스러운 표현 검수와 Tistory HTML 검수를 통과한 경우에만 성과 후보 큐로 넘긴다.
8. 통과 상품이 여러 개면 각각 발행하지 않고 한 편의 묶음 글로 합친다.
9. 당일 Tistory 발행 이력과 남은 예약을 비교해 앞뒤 간격이 가장 긴 중간 시점을 선택한다.
10. 실제 발행 직전에 데이터와 이미지를 한 번 더 확인한다. 오래된 candidate나 screenshot은 사용하지 않는다.

## 후보 판정 기준

필수 조건:

- `dataReady=true`
- 10분봉 데이터 관측 시각이 현재 기준 10분 이내
- 이전 snapshot 이후 `completedTrades` 증가
- 이전 snapshot 이후 `realizedProfit` 증가
- 새로 캡처한 차트에 최근 진입·청산 표식이 확인됨
- 같은 성과 snapshot으로 아직 글을 만들지 않음

권장 우선순위:

- 상품별 최근 성과 분포 상위 25%에 해당하는 실현 손익 증가
- 한 번의 우연한 거래보다 두 개 이상의 타점이 자연스럽게 이어진 차트
- 진입과 청산이 화면에서 식별 가능하고 설명할 만한 흐름이 있음
- 현재 포지션이 있으면 실현 손익과 미실현 손익을 명확히 분리할 수 있음

차단 조건:

- 누적 실현 손익만 있고 이전 snapshot이 없어 이번 정각에 늘어난 성과인지 알 수 없음
- 완료 거래 수는 늘었지만 손익 증가분이 0 이하
- 화면의 거래 방향과 구조화 데이터가 충돌
- 차트가 흐리거나 진입·청산 표식이 잘림
- 데이터 또는 이미지가 10분 이상 오래됨
- 자연스러운 말투/사실성/SEO/HTML 검수 실패

## 중복과 과다 발행 방지

- 동일 `상품 + 시간봉 + completedTrades + realizedProfit` 조합은 한 번만 사용한다.
- 같은 상품은 24시간에 한 번만 추가 포스팅한다.
- 성과 추가 포스팅은 하루 최대 1편을 기본값으로 둔다. 통과 상품이 여러 개면 한 편에 묶는다.
- 정규 07:00/08:00/21:00/22:00 선물 브리핑과 같은 screenshot·같은 성과를 재사용하지 않는다.
- 여러 상품이 동시에 통과하면 정규화 점수가 가장 높은 상품부터 고른다.

## 발행 간격과 묶음 정책

현재 Tistory 정규 예약 시각은 `07:00`, `08:00`, `09:00`, `13:30`, `19:00`, `21:00`, `22:00`이다. 성과 스캐너는 정각에 후보를 발견하더라도 즉시 발행하지 않는다.

- 후보는 먼저 `hourly_futures_performance_queue`에 적립한다.
- 이미 발행된 글과 앞으로 발행될 예약 글을 모두 놓고 가장 긴 공백을 계산한다.
- 앞뒤 글과 각각 2시간 이상 떨어진 시점을 우선 선택한다.
- 2시간을 확보할 수 없으면 최소 1시간 간격을 반드시 지킨다.
- 1시간도 확보할 수 없으면 다음 긴 공백 또는 다음 영업일로 넘긴다.
- 후보 발견 직후 다른 글이 발행됐거나 곧 예약돼 있으면 연속 발행하지 않는다.
- 같은 대기 구간에 통과한 상품은 상품별 개별 글이 아니라 한 편의 성과 모음 글로 합친다.
- 묶음 글은 최대 3개 상품만 본문에서 자세히 다루고, 나머지는 다음 후보로 보류한다.

현재 편성에서 우선 검토할 공백은 다음과 같다.

1. `09:00 ~ 13:30`: 약 4시간 30분
2. `13:30 ~ 19:00`: 약 5시간 30분
3. `22:00 ~ 다음 영업일 07:00`: 야간 공백이지만 심야 발행은 피하고 다음 영업일 대기로 넘긴다.

실제 시각은 고정하지 않고 그날의 성공·실패·지연 이력을 포함해 다시 계산한다. 예를 들어 13:30 글이 14:00에 늦게 발행됐다면 성과 글도 그 실제 발행 시각에서 최소 1~2시간 뒤로 밀어야 한다.

묶음 제목 예시:

- `오늘 타점이 좋았던 선물 3개: WTI·나스닥·금 10분봉 복기 | 2026.07.14 급등포착`
- `WTI·금 10분봉 매매 타점 복기: 이번 구간 누적 성과 확인 | 2026.07.14 급등포착`

묶음 본문은 공통 도입 뒤 상품별로 `차트 -> 최근 진입·청산 흐름 -> 검증된 손익 증가분 -> 현재 포지션`을 짧게 정리한다. 숫자와 문장을 복사하듯 반복하지 않는다.

## 글 구성

1. SEO 제목: 상품명, 10분봉, 매수/매도 타점, 검증된 성과, 날짜를 자연스럽게 포함한다.
2. 짧은 도입: 오늘 차트에서 왜 이 상품이 눈에 들어왔는지 사람 말투로 시작한다.
3. 최신 10분봉 screenshot
4. 화면에서 확인되는 진입·청산 흐름을 2~3문단으로 복기한다.
5. 누적 성과와 이번 정각 증가분을 분리해 작은 표로 정리한다.
6. 현재 포지션 유무와 다음에 볼 가격대 또는 조건을 짧게 적는다.
7. 급등포착 링크와 매매 타점 확인 문구를 넣는다.
8. 개인 기록이며 수익을 보장하지 않는다는 문구로 마무리한다.

## 성과 표현 원칙

- `누적 +16.14pt`와 `이번 완료 거래 +1.44pt`를 섞지 않는다.
- 현재 포지션이 없으면 미실현 수익이 난 것처럼 쓰지 않는다.
- 실제 매수·매도 방향은 구조화 데이터와 차트가 일치할 때만 쓴다.
- `무조건 수익`, `따라 하면 된다`, `확정 수익` 표현은 금지한다.
- 좋은 타점 사례는 `이번 구간에서는 매수 타점이 결과적으로 잘 잡혔습니다` 정도로 설명한다.

## 이번 샘플 해석

제공된 WTI 크루드오일 화면은 2026-07-14 11:13경의 10분봉이다. 화면상 누적 실현 손익은 `+16.14pt`, 완료 거래는 `55회`, 승률은 `60%`, 현재 포지션은 `진입 없음`이다. 따라서 샘플에서는 `최근 한 거래가 +16.14pt 수익`이라고 쓰지 않고, `56일 누적 성과 +16.14pt와 최근 매수·청산 타점 복기`로 표현한다.
