# 01_REQUIREMENTS

## MVP 필수 기능

1. 관리자 기본 화면
2. LLM Provider 설정
3. OpenAI API / Local LLM 선택 구조
4. 블로그 프로필 관리
5. 서비스/브랜드 프로필 관리
6. 글 생성 입력 화면
7. 글 기획서 생성
8. 본문 및 HTML 생성
9. 품질검사
10. Blogger 초안 저장
11. 예약 발행
12. 발행/LLM 호출 로그

## 초기 제외 기능

- 자동 키워드 수집
- 상위글 자동 분석
- 이미지 파일 분석
- 썸네일 자동 생성
- 성과 분석
- 자동 리라이트
- 멀티채널 자동 발행
