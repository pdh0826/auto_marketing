# 22_VIDEO_OPERATOR_RUNBOOK

## Scope

This runbook covers manual review of local Daily Brief video artifacts generated by the internal Blog Growth Agent video automation module.

Manual review outside the app means local-only inspection with a local file browser, local media player, or local editor. It does not mean upload, publish, schedule, or external platform submission.

## Required Local Artifacts

Before reviewing a video, generate and read back the local package from the Daily Brief wizard:

1. package preview
2. local package generation
3. card PNG render
4. MP4 local render
5. upload metadata package
6. package readback

Expected local directory:

```text
local-data/video-automation/daily-brief/{packageSlug}/
```

Expected review artifacts:

- `manifest.json`
- `storyboard.json`
- `subtitles.srt`
- `subtitles.vtt`
- `cards/*.png`
- `card-render-report.json`
- `video.mp4`
- `mp4-render-report.json`
- `upload/operator-checklist.md`

## Required Readback State

Proceed with local review only when readback shows:

- `stale=false`
- current source hash matches the saved manifest source hash
- `video.mp4` exists and has non-zero bytes
- `manifest.json` exists
- `mp4-render-report.json` exists
- `upload/operator-checklist.md` exists
- operating repo touched is false
- server 3004 touched is false
- external write routes enabled is false
- scheduler mutation enabled is false
- secret read required is false

Stop if any of these are missing, stale, or unexpected.

## Review Checklist

Source and hash:

- Confirm the Daily Brief run id and market date are the intended source.
- Confirm the source hash shown in the manifest/readback is the same hash used by MP4 and upload metadata.
- Confirm the saved package is not stale after any Daily Brief source update.

Visuals:

- Open `video.mp4` locally.
- Confirm the video is vertical 1080x1920.
- Confirm all cards are readable on a mobile-sized viewport.
- Confirm stock, ETF, futures, and market numbers match the source Daily Brief.
- Confirm the final card is the investment risk note.

Storyboard and subtitles:

- Compare `storyboard.json` scene count with card count.
- Confirm scene order matches the rendered cards.
- Confirm subtitles do not overflow and match the visible scene context.
- Confirm the MP4 is silent unless a future approved audio patch explicitly changes that contract.

Metadata:

- Open `upload/operator-checklist.md`.
- Confirm `Upload enabled: false`.
- Confirm `External platform upload: false`.
- Confirm the title, description, and hashtags are review drafts only.

## Forbidden During Review

Do not:

- upload to YouTube, Instagram, TikTok, Blogger, or Tistory
- save a Blogger or Tistory draft
- publish or schedule publish
- mutate an existing content item
- mutate a Daily Brief source run
- change scheduler config
- enable hidden upload/write flags
- read, print, paste, or commit secrets
- copy `storagePath` or local absolute paths into public metadata
- use the operating `/Users/pdh0826/blog-growth-agent` repo or 3004 server for this review

## Failure Handling

If readback is stale:

1. regenerate the local package from the current Daily Brief source
2. rerender cards
3. rerender MP4
4. regenerate upload metadata
5. run readback again

If `ffmpeg` fails or `video.mp4` is missing:

- keep the failure report as local evidence
- do not attempt upload or publishing
- fix the local renderer/runtime in a separate patch

If any secret-like value, local absolute path, or capture `storagePath` appears in a public-facing artifact:

- stop review
- treat it as a blocking safety bug
- do not distribute the artifact

## Validation

Before accepting a VIDEO patch, run:

```bash
npm run verify:video-automation
```

This keeps source hash behavior, stale readback, safety boundary checks, lint, typecheck, and build tied to the same verification command.
